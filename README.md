# Qadam AI

MVP для кейса AI Sana «Геймификация практических заданий». Бизнес с помощью ИИ превращает черновик задачи в полную карточку, получает рейтинг готовности от 0 до 100 и публикует задачу в каталоге. Студенческие команды откликаются на задачи, а бизнес сам выбирает, с кем работать.

## Быстрый старт

Нужны Python 3.11+ и Node.js.

### 1. Переменные окружения

```bash
cp .env.example .env
```

Заполните `.env`:

| Переменная | Что указать |
|---|---|
| `OPENAI_API_KEY` | ключ OpenAI API |
| `OPENAI_MODEL` | модель с поддержкой Structured Outputs |
| `AI_MODE` | `auto` — OpenAI, если заданы ключ и модель, иначе заглушка; `stub` — всегда заглушка |

### 2. Бэкенд

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Проверка: http://localhost:8000/api/health. Документация API: http://localhost:8000/docs.

### 3. Фронтенд

```bash
cd front
npm install
npm run dev
```

Приложение: http://localhost:5173.

## Данные

При первом запуске бэкенд создаёт `backend/data/db.json` из `backend/data/seed/*.json`. Файл `db.json` не коммитится.

Сброс данных к исходным (перед демо и после изменения seed-файлов):

```bash
curl -X POST http://localhost:8000/api/demo/reset
```

## Структура

```
backend/app/
  main.py          # приложение, роутеры, единый формат ошибок {"error": "..."}
  schemas.py       # модель данных и форматы API
  storage.py       # хранилище в JSON-файле
  llm.py           # вызовы OpenAI
  routers/         # эндпоинты по фичам
  services/        # логика: рейтинг, конструктор, рекомендации
  prompts/         # промпты
backend/data/seed/ # тестовые данные
front/             # React-приложение
```
