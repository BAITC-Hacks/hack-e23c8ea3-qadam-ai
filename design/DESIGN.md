# Qadam AI — дизайн-спецификация для фронтенда

> Для Cursor / Codex. Источник правды по UI — `design/QadamPrototype.jsx`. Это рабочий прототип: вся логика сценария кейса в нём уже есть.
> Живое превью: откройте `design/preview.html` в браузере (нужен интернет, чтобы загрузились Tailwind CDN и шрифты).

## 0. Задача фронта

Перенести прототип в `front/` так, чтобы работал сквозной сценарий кейса AI Sana:

**черновик → AI-уточнение (≥3 вопроса) → редактируемая карточка → рейтинг 0–100 → публикация в каталог по рейтингу → отклик команды → ручной выбор бизнеса → баллы команде за этап**

Визуал, тексты и поведение берите из прототипа 1:1. Можно улучшать структуру кода, но не дизайн.

## 2. Токены — «человечный» стиль

Характер: тёплый, светлый, разговорный. Интерфейс похож на беседу с помощником, а не на панель управления. Мягкие тени вместо неонового свечения, округлые формы, живые люди в командах.

| Токен | Значение | Tailwind | Где |
|---|---|---|---|
| Фон страницы | `#F6F4F1` (тёплый светло-серый) | `bg-[#F6F4F1]` | страница; два размытых пятна `orange-200/40` и `sky-200/40` |
| Поверхность | белый + мягкая тень | `bg-white rounded-3xl border-stone-200/80 shadow-[0_1px_2px_rgba(41,37,36,.04),0_12px_32px_-20px_rgba(41,37,36,.18)]` | карточки (`Panel`) |
| Граница | stone-200 | `border-stone-200` | карточки, инпуты |
| Текст | stone-900 / stone-700 / stone-500 / stone-400 | | заголовки / тело / подписи / плейсхолдеры |
| **Акцент** | `#f97316` (orange-500), текст `orange-600` | `bg-orange-500 hover:bg-orange-600 text-white` | **только** помощник, рейтинг, главная кнопка, активная навигация |
| Тень акцента | `0 16px 40px -16px rgba(234,88,12,.35)` | inline `boxShadow` | кольцо рейтинга, блок помощника, приоритетные задачи |
| Ответ пользователя | stone-900 фон, stone-50 текст | | «пузырь» ответа в диалоге |

Правило одного акцента: оранжевый не используется для декора.

**Уровни готовности** (семантические цвета):

| Баллы | Уровень | Цвет | Поведение в каталоге |
|---|---|---|---|
| 0–39 | Черновик | stone-400, чип `bg-stone-100 text-stone-600` | виден, плашка «Требует уточнения — откликаться можно» |
| 40–69 | Рабочая | amber-400, чип `bg-amber-50 text-amber-800` | можно откликаться, помощник может рекомендовать |
| 70–89 | Готовая | emerald-500, чип `bg-emerald-50 text-emerald-700` | повышенная позиция |
| 90–100 | Приоритетная | orange-500 + тень акцента | выделена рамкой `border-orange-300` |

**Статусы откликов**: На рассмотрении (stone), Выбрана (emerald), Отклонена (rose).

**Аватары команд**: круг с первой буквой имени капитана. Пастельный цвет закреплён за командой (rose / sky / amber / emerald / violet, `-100` фон и `-700` текст). Цвет нужен только для узнаваемости.

**Типографика**

| Роль | Шрифт | Использование |
|---|---|---|
| Display | Rubik 600, letter-spacing −0.015em | H1 (24/28px), крупные числа рейтинга, бренд, буквы в аватарах |
| Body | Onest 400/500/600 | весь интерфейс, 14–15px; текст в диалоге 15px |
| Mono | JetBrains Mono | баллы `14/20`, позиции `#2`, JSON |

Числа — `tabular-nums`. Надзаголовки: 11px, uppercase, tracking 0.16em, `text-orange-600`.

**Форма**: кнопки `rounded-full`; карточки и пузыри `rounded-3xl`; у пузыря помощника острый угол сверху слева (`rounded-tl-md`), у ответа пользователя — снизу справа (`rounded-br-md`); инпуты `rounded-xl`.

**Тон текстов**: на «вы», коротко, по-человечески. «Расскажите, что хотите решить», «Помощник читает…», «Учтено в рейтинге», «Кто хочет взяться за задачу», «Решаете только вы». Слово «AI» в интерфейсе — только в «Как работает AI-помощник» (для жюри), в остальных местах «помощник».

## 3. Каркас и адаптив

```
≥1280 (xl)   [Sidebar 256] [Main, max-w 3xl–4xl] [Wow-панель 360, sticky, своя прокрутка]
1024–1279    [Sidebar 256] [Main] + wow-панель под основным контентом
<1024        [Topbar: логотип · Бизнес/Студенты · 🌐 РУС] [Main] [Wow-панель ниже] [Bottom tab bar]
```

- **Sidebar**: логотип, переключатель ролей «Бизнес / Студенты», навигация с бейджами, карточка пользователя (бизнес: «Айжан, управляющая, Qala Service») или выбор команды (студенты), «Как работает AI», «Сбросить демо».
- **Мобильная версия**: нижний таб-бар с `env(safe-area-inset-bottom)`; drawer задачи на весь экран; модалка AI выезжает снизу; фильтры и рекомендации прокручиваются горизонтально (`overflow-x-auto`, отрицательные поля `-mx-4 px-4`); в конструкторе под степпером закреплена полоса рейтинга (`sticky top-[61px]`).
- Горизонтальной прокрутки страницы быть не должно (проверено на 390px).

## 4. Экраны

### Бизнес → «Новая задача» (3 шага)
Степпер: Ваша задача · Пара вопросов · Карточка.
1. **Ваша задача**: заголовок «Расскажите, что хотите решить», textarea «Что происходит и что хочется изменить», счётчик слов, отрасль, кнопка «Продолжить с помощником». Ниже чипы «Не знаете, с чего начать? Возьмите пример» (5 примеров). Во время анализа — shimmer и «Помощник читает…».
2. **Пара вопросов — диалог**: справа тёмный пузырь с черновиком пользователя. Слева пузырь «Помощник Qadam» (оранжевый аватар со Sparkles): «мне не хватает N из 7 деталей… я ничего не буду придумывать за вас» и чипы найденного (emerald) и недостающего (пунктир). Дальше 3–5 пар «вопрос помощника → поле ответа». Поле ответа выглядит как пузырь пользователя: пустое — белое с пунктиром, заполненное — тёмное, под ним «✓ Учтено в рейтинге». У вопроса бейдж «до +N». Рейтинг справа пересчитывается на каждое нажатие клавиши.
3. **Карточка**: баннер «Карточка собрана только из ваших слов — помощник ничего не добавил от себя». Поля с бейджами `Критерий 14/20`, пустые — с пунктиром. Обязательный чекбокс подтверждения. Кнопка «Опубликовать · N баллов» → тост «Опубликовано · позиция #K в каталоге» → каталог, новая задача подсвечена.

Wow-панель конструктора: большое кольцо рейтинга (засечки на 40/70/90) + лесенка уровней; разбивка по 7 критериям (полосы); «Что поднимет рейтинг» (топ-4 подсказки с «+N»); карточка «Рост рейтинга» (+Δ крупно, спарклайн Черновик → Ответы → Сейчас).

### Каталог (обе роли)
Поиск; чипы тем (отрасли); чипы уровней; список, **отсортированный по рейтингу** (при равенстве — новее выше). Строка задачи: `#позиция`, чип уровня, название, компания и отрасль, теги, число откликов, мини-кольцо рейтинга. Для студентов сверху блок «Помощник советует {команда}»: до 3 задач с рейтингом ≥40, у которых совпадают навыки или интересы, с подписью «каталог не ограничен».

### Drawer задачи
Шапка с кольцом рейтинга, 7-сегментная разбивка, все поля карточки (пустые: «Не указано бизнесом»). Нижняя часть:
- студент: форма отклика «Идея, План, Срок, Ссылка» с валидацией (идея ≥5 слов, план ≥3 слов, ссылка `https://…`), ошибки под полями розовым;
- студент, уже откликнувшийся: статус;
- бизнес, своя задача: кнопка «Отклики на задачу · N».

### Бизнес → «Отклики»
Заголовок «Кто хочет взяться за задачу». Табы по своим задачам. Баннер «Помощник не выбирает команду за вас». Сетка карточек откликов (2 колонки от md): аватар капитана, команда, «Айдана, капитан · 4 в команде», статус, навыки-чипы, идея в кавычках крупнее, план, срок, ссылка. Кнопки «Отклонить» и «Выбрать» (можно выбрать несколько). Для выбранной: «Подтвердить этап → +50 баллов команде». Для отклонённой: «Вернуть на рассмотрение».

### Студенты → «Мои отклики»
Список: мини-кольцо, задача, компания и срок, статус, «+50 баллов» после подтверждённого этапа.

### Wow-панель вне конструктора
Три плитки: задач / **средний рейтинг** (оранжевый) / откликов. «Рост рейтинга» последней опубликованной задачи. «Готовность каталога»: полоса распределения по 4 уровням. Для студентов: лидерборд «Баллы команд за прогресс». **Трекер сквозного сценария** из 8 шагов показан всегда: выполненные закрашены оранжевым, текущий обведён мягким кольцом.

### Модалка «Как работает AI»
Промпт, вход (JSON), выход (JSON). Три правила: без выдуманных фактов; невалидный ответ → шаблонные вопросы; решает человек. Закрывает требование кейса «показать промпт, формат входа и выхода и обработку некорректного ответа».

## 4a. Языки: ҚАЗ / РУС / ENG

**Где стоит переключатель**
- **Десктоп (≥1024)**: внизу сайдбара, над «Как работает AI». Подпись «🌐 Язык» и сегмент-таблетка из трёх кнопок `ҚАЗ · РУС · ENG`: активная кнопка белая с тенью, остальные серые. Переключатель всегда на виду, но не отвлекает от работы.
- **Мобильный (<1024)**: в шапке справа кнопка-таблетка «🌐 РУС» с текущим кодом языка (иконка оранжевая). По нажатию снизу выезжает шторка «Меню»: три больших пункта с названиями на родном языке («Қазақша», «Русский», «English») и галочкой у текущего, под разделителем «Как работает AI» и «Сбросить демо». Отдельная кнопка `{}` в шапке больше не нужна.
- Порядок: **ҚАЗ первым** (государственный язык), затем РУС и ENG. Коды: `kk`, `ru`, `en`.

**Правила**
- Переводится только интерфейс: навигация, заголовки, кнопки, подсказки. Задачи и отклики остаются на языке автора.
- При смене языка обновлять `document.documentElement.lang` и сохранять выбор в `localStorage` (`qadam.lang`). По умолчанию брать `navigator.language`, если он ru/kk/en, иначе `ru`.
- Реализация: словари `src/i18n/{kk,ru,en}.js` + `LangContext` + хук `useT()`; ключи как в `I18N` прототипа. Если ключа нет, показывать `ru`. Библиотека не обязательна; при желании подойдёт `react-i18next`.
- Казахские строки длиннее русских примерно на 10–20%: не задавать кнопкам фиксированную ширину, у длинных подписей в табах и степпере оставить `truncate`.
- В прототипе переведены оболочка, заголовки экранов, степпер, главные кнопки, панели рейтинга и трекер. Остальные строки (вопросы помощника, подсказки, тосты, формы) Cursor переносит в словари тем же способом.

## 5. Логика (уже в прототипе — перенести в `src/lib`)

**Рейтинг** — `scoreCard(card)`: баллы = вес × качество поля.
Качество по числу слов: 0 → 0; 1–3 → 0.35; 4–9 → 0.7; ≥10 → 1.

| Критерий | Вес | Поля | Особое правило |
|---|---|---|---|
| Контекст и потребность | 20 | context, need | среднее двух полей |
| Данные и материалы | 20 | data | |
| Ожидаемый результат | 15 | result | |
| Критерии успеха | 15 | criteria | без цифры — максимум 0.6 |
| Ограничения | 10 | constraints | |
| Пользователи | 10 | users | |
| Связь с бизнесом | 10 | contact, format | contact без email, телефона или Telegram — максимум 0.5; итог = 0.6·contact + 0.4·format |

Для каждого критерия возвращается `tip` — подсказка, что добавить. Рейтинг пересчитывается при каждом изменении.

**AI** — `analyzeDraft(draft)` → `{ detected, missing, questions[3..5] }`. Это локальная заглушка на ключевых словах. Для подключения LLM используйте промпт `AI_PROMPT` и прогоняйте ответ через `validateAIResponse(raw)`: при невалидном JSON или менее чем 3 вопросах подставляются шаблонные вопросы. Карточка собирается **только** из черновика (→ context) и ответов (→ соответствующие поля); название берётся из первого предложения черновика.

**Синтетические данные** (`SEED_*`, вынести в `src/data/*.json`): 5 черновиков, 5 задач (рейтинги 98 / 88 / 78 / 48 / 21 — все 4 уровня), 5 команд, 5 откликов (3 из них на задачу «своей» компании Qala Service).

## 7. Сценарий демо (5 минут)

1. Бизнес → Новая задача → чип «Нужен бот для записи клиентов…» → Проанализировать (рейтинг **7**).
2. Ответить на 5 вопросов → рейтинг растёт вживую (**~68**, «Рабочая»).
3. Собрать карточку → дописать формат, пользователей, результат → **~94**, «Приоритетная» → подтвердить → Опубликовать → **позиция #2**.
4. Студенты → команда Qazaq Devs → задача в каталоге → отклик.
5. Бизнес → Отклики → Выбрать → Подтвердить этап → **+50 баллов**. Трекер показывает **8/8**.
6. «Как работает AI» — показать промпт, JSON и обработку ошибок.

«Сбросить демо» в сайдбаре возвращает всё к исходному состоянию.

## 8. Нельзя

- Добавлять второй акцентный цвет, неон, glow-эффекты или тёмную тему.
- Автоматически назначать команду или скрывать задачи с низким рейтингом.
- Дописывать в карточку текст, которого не вводил пользователь.
- Делать острые углы и плотные «таблицы»: кнопки `rounded-full`, карточки `rounded-3xl`, воздух между блоками.
