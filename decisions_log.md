# Журнал решений

## 2026-09-23 — тема интерфейса

- Решение: светлая/тёмная тема через палитру CSS и отдельный React-провайдер; начальная тема светлая, ручной выбор — строка `light` или `dark` в `qadam.theme`.
- Причина: единый вид всех экранов без новых зависимостей и без вмешательства в логику задач и AI.
- Контракт: добавлен только ключ настройки интерфейса; `qadam.session`, формула рейтинга и API не меняются. Недоступное хранилище не мешает переключению в текущей вкладке.
