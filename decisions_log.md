# Решения Qadam AI

## 2026-09-23, Asia/Almaty — конструктор Марата

- Решение: сохраняем FastAPI + React и публичные модели из `backend/app/schemas.py`, реализуем только сервис, роутер, промпты и тесты Марата. Причина: действующий командный контракт, требование Codex.md не менять рабочую архитектуру без согласования. Контракт: `/api/constructor/analyze` и `/api/constructor/card` без изменений полей.
- Решение: отдельные строгие модели ответа LLM живут в сервисе; обязательные строковые поля карточки допускают null внутри ответа модели, а публичная Card получает пустые строки. Причина: совместить неизвестные значения по Codex.md с существующим строковым API. Контракт с UI не меняется.
- Решение: `answers.contact` не передаётся модели; email, телефон и ссылки/ники связи в свободном тексте маскируются локально. Контакт возвращается из исходного ввода кодом, а не из догадки модели. Причина: Codex.md §7. Остальной текст проходит ограниченную локальную маскировку, которая не гарантирует удаления всех персональных данных.
- Решение: при выключенном AI сразу 503; при ошибке провайдера или проверке ответа максимум две попытки, затем 503. Заглушка остаётся на фронтенде у Айгерим/Арсена. Причина: действующая архитектура AI-only бэкенда. Тайм-аут существующего llm.py (30 с) передан Айгерим для согласования с требованием Codex.md (20 с); файл не меняем.
