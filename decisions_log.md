# Решения Qadam AI

## 2026-09-23 14:25 (Asia/Almaty) — контракт этапа 0

- **Решение:** сохраняем React/Vite во фронтенде и FastAPI/Pydantic/OpenAI на бэкенде; бэкенд отвечает только за ИИ. **Причина:** это действующий стек и разделение ответственности в `AGENTS.md`; предложение Streamlit/SQLite в `Codex.md` относится к пустому проекту. **Контракт:** данные, рейтинг, каталог и отклики остаются во фронтенде. Упомянутое в плане прежнее решение о JSON-хранилище расходится с текущим `AGENTS.md`; вопрос отложен до отдельного этапа, без изменения хранения сейчас.
- **Решение:** сохраняем публичные схемы `backend/app/schemas.py` без переименований. **Причина:** они совпадают с `EMPTY_CARD` в `front/src/data/seed.js`, `QUESTION_BANK` в `front/src/lib/ai.js` и API в `AGENTS.md`. **Контракт:** `Card` содержит строковые `title`, `industry`, `context`, `need`, `users`, `data`, `constraints`, `result`, `criteria`, `contact`, `format`; поля вопросов — `need`, `users`, `data`, `constraints`, `result`, `criteria`, `contact`. Черновик — минимум 3 слова. `industry` в запросах по текущей схеме допускает пустую строку; `answers` обязателен для сборки карточки.
- **Решение:** оставляем форматы HTTP: `GET /api/health` → `{ok, ai_mode, ai_available, openai_key, model}` (`openai_key` — признак наличия, не ключ); `POST /api/constructor/analyze` с `{draft, industry}` → `{detected, missing, questions: [{field, text}], source: "ai"}`; `POST /api/constructor/card` с `{draft, industry, answers}` → `{card, warnings, source: "ai"}`. Ошибки — `{"error": str}` со статусом 4xx/5xx; `source` допускает `"ai" | "stub"` для общего контракта с фронтендом. **Причина:** эти формы уже определены в `AGENTS.md` и Pydantic; успешный ответ бэкенда помечается `"ai"`, локальная заглушка фронтенда — `"stub"`. **Контракт:** потребители и исполнитель роутера используют эти имена и типы.
- **Решение:** `llm.ask_json` делает ровно одну попытку и возвращает типизированный Pydantic-ответ либо `LLMError`. Сервис конструктора отвечает максимум за один повтор при ошибке и за контролируемую `503`; фронтенд при недоступном или некорректном API-ответе включает явную локальную заглушку. **Причина:** исключаем вложенные повторы и сохраняем рабочий сценарий без бэкенда. **Контракт:** модели ответа LLM отдельны от публичных схем и не содержат значений по умолчанию; подтверждение и публикация карточки остаются действиями бизнеса.
