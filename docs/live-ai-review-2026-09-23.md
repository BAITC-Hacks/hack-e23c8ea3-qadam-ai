# Проверка живого ИИ, 2026-09-23

Модель: `gpt-5.4-mini`, режим `AI_MODE=auto`. Входы — пять синтетических случаев из `backend/tests/fixtures/constructor_cases.json`. Запуск: `cd backend && .venv/bin/python -m tests.manual_constructor --live`. Ключ в отчёт не включён. Дополнительно оба POST-маршрута прошли через Vite-прокси с HTTP 200, а короткий черновик дал ожидаемый HTTP 422.

| Случай | Наблюдение после исправлений |
|---|---|
| `weak` | Анализ спросил про данные, результат и критерии вместе с уточнениями о пользователях и ограничениях. Фразы «Пока не знаю, нужно уточнить» и «Ещё не определили» оставили поля пустыми; результат из ответа сохранён. |
| `partial` | Карточка сохранила Excel за три месяца, двух менеджеров, срок две недели и критерий 10 минут. Один повторный прогон анализа вернул 503 после двух ответов модели, не прошедших проверку; отдельный повтор через Vite дал HTTP 200 с вопросами про критерии, контакт и состав результата. При 503 клиент переключается на локальную заглушку. |
| `complete` | Анализ задал три уточняющих вопроса; карточка сохранила условия доступа после выбора команды, локальный запуск, срок, критерий двух минут и дополнения из ответов. |
| `contradictory` | Анализ попросил выбрать актуальный срок. Карточка оставила оба срока и предупредила о противоречии. |
| `contacts` | Контакт из ответа сохранён в карточке; новых метрик и срока нет. Маскирование контактов до вызова модели проверяется отдельным тестом адаптера. |

Модель может возвращать ответ, который не проходит содержательную проверку. Сервер делает не более одной повторной попытки и выдаёт 503, после чего фронтенд показывает локальную заглушку. Автоматические тесты, реальные HTTP-ответы и просмотр JSON не заменяют ручной проход по кнопкам в браузере; он остаётся непроверенным.
