# План Марата — feat/constructor

Работаем по Codex.md. Публичный API и стек сохраняем по текущему AGENTS.md и schemas.py. Контакты перед вызовом модели маскируем, неизвестные значения внутреннего AI-ответа допускают null и преобразуются в пустые строки публичной карточки.

1. Зафиксировать границы, контракт и решения. Критерий: изменения только в файлах Марата и его документации.
2. Написать и запустить падающие тесты: API, 3–5 неповторяющихся вопросов, согласованность detected/missing, невалидный JSON, отказ провайдера, защита контактов.
3. Перенести и адаптировать два промпта в `backend/app/prompts/`; реализовать сервис в `backend/app/services/constructor.py`.
4. Подключить два POST-эндпоинта в `backend/app/routers/constructor.py`. Проверить через TestClient и локальный HTTP; для ошибок — единый формат приложения.
5. Подготовить пять примеров AI-качества: слабый, средний, полный, противоречивый, с контактами. Отдельно отметить реальные прогоны модели и тесты с подменённым ответом.
6. Обновить только раздел README про ИИ и свою документацию. Просмотреть diff, пройти pytest и Ruff, сделать коммит, синхронизировать main, составить отчёт.
7. После интеграции Айгерим пройти UI вместе с командой: черновик → вопросы → карточка → подтверждение → публикация → два отклика → ручное решение → подтверждённый этап.

## Границы ответственности

- Марат: `routers/constructor.py`, `services/constructor.py`, `prompts/*.md`, тесты конструктора, документация его части.
- Айгерим: `main.py`, `schemas.py`, `llm.py`, вызовы API и fallback в UI, прокси. Не правим эти файлы; необходимые изменения передаём через Марата.
- Арсен: UI, рейтинг, каталог, отклики, локальное сохранение, локальная заглушка. Не правим эти файлы; замечания передаём через Марата.
- Не переносим данные на бэкенд, не меняем рейтинг и статусы проекта. Секреты не читаем в вывод и не коммитим. Push — только по отдельному запросу.

## Что требует согласования с командой

- В Codex.md один запрос ограничен 20 секундами, в `llm.py` сейчас 30. Айгерим должна согласовать тайм-аут и ожидание фронтенда с учётом одного повтора.
- В `llm.py` логируются фрагменты исключений и отказов провайдера. Айгерим должна проверить маскирование этих логов; сервис Марата пишет только тип ошибки и номер попытки.
- Codex.md и AGENTS.md расходятся по формуле рейтинга, хранению, статусам, начислению баллов и представлению неизвестного. Публичный контракт не меняем молча; решением команды нужно устранить эти расхождения в документах.
